# AARYA Mission Control

AARYA Mission Control — AI Agent Orchestration Platform with 15 Marvel-coded agents, cyberpunk 3D HQ, gamification engine.

## Architecture

```
+---------------------------------+
|       AARYA Mission Control     |
|    (AI Orchestration Platform)  |
+---------------------------------+
|                                 |
|  Agents  |  HQ (3D)  |  Game    |
|  Engine  |  Engine   |          |
+---------------------------------+
```

## Tech Stack

- React
- Three.js
- Zustand
- Tailwind CSS

## Setup Instructions

1. Clone the repository
2. Install dependencies using `npm install`
3. Run the project using `npm start`
